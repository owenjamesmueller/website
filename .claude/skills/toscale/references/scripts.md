# Script templates

Numbers in words as spoken. Short sentences. No "in this video", no greeting, no outro.

## A. Ladder (60-110 words, 20-45 s)
```
[0s PROMISE]  {Category}, from smallest to biggest. (counter/rail already visible)
[STEPS 1-4]   {Item}: {value}. {5-10 word surprising fact.}      (~3 s each)
[STEPS 5-9]   {Item}. {value}. {3-6 word fact.}                 (~2 s each)
[OPEN LOOP]   But nothing prepares you for number {n}.          (~65% through)
[STEPS 10-12] {Item}. {value}.                                   (~1.5 s each)
[PAYOFF]      {Final item}: {value}. {One twist line that loops into the first line.}
```

## B. Descent (80-140 words, 30-55 s)
```
[0s PROMISE]  This is how deep {place} really goes. (gauge at 0 m)
[WAYPOINTS]   {depth}: {thing that lives/sits here}. ... (every 2-3 s, gaps get longer, counter speeds up)
[OPEN LOOP]   Most people think it ends here. It doesn't.
[PAYOFF]      {deepest point + one chilling or absurd fact}. 
[LOOP LINE]   ...and we've only seen {x}% of it. (cut to frame 0)
```

## C. Story (110-145 words, 40-58 s)
```
[0s COLD OPEN]  The most dramatic moment first, one line: "This is Earth one hour after the Moon vanishes."
[T+0]           The trigger, one sentence. Hook: "At first, nothing happens."
[T+1..T+4]      Each beat a bigger time jump (seconds -> hours -> years), 6-9 s each,
                each ending: "But that's not the worst part." / "Then {x}."
[OPEN LOOP]     ~65%: "And the last change is the one nobody expects."
[PAYOFF]        The furthest point in time + one twist line. Cut. Under 58 s total.
```
